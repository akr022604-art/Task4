# 📝 Notes Manager (Java)

A simple **text-based Notes Manager** built in Java.  
This program allows you to **add notes**, **view saved notes**, and **exit**.  
Notes are stored in a text file using `FileWriter` and displayed using `BufferedReader`.

## 🚀 Features
- Add a new note (appends to `notes.txt`)
- View all notes (reads from `notes.txt`)
- Exit the program safely
- Uses **FileWriter** for writing and **BufferedReader** for reading

---

## 📂 Project Structure
